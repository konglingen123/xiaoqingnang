# 小青囊独立内容后台

这是与用户端 H5 分离的桌面 Web 管理系统。部署后与用户端共用域名，固定使用 `/admin/` 路径；用户端不提供后台入口。

当前后台只向编辑者提供一条固定录入流程：问题 → 方法 → 使用范围 → 注意事项 → 风险边界 → 案例集。复杂的数据关系不直接暴露在界面上。

一条资料只讲一个方法。穴位或功法必须填写准确位置，并为每个步骤补齐动作、力度、时间或次数、每日频率及准确素材。案例为可选项，但一旦添加，就必须填写背景、实际方法、主观记录、个体差异与原文位置。编辑者可以随时保存草稿，并直接看到尚未填写的项目。

所有新内容默认保存为草稿。后台不会自动补齐方法参数，也不会把草稿直接送入用户端。填写完整只代表可以进入人工审核；编辑者确认来源、安全边界和公开文案后，使用“保存并发布”进入前台。

内容统一保存在本机 `.runtime/content.db` SQLite 数据库中，不再依赖浏览器缓存。首次打开后台时创建管理员，之后必须登录；保存、发布、撤回、上传与登录都会留下操作记录。只有明确发布且通过完整性检查的资料会进入前台公开接口。旧版浏览器草稿会在首次登录后尝试迁移一次。

“导出备份”会下载包含全部草稿与已发布内容的 JSON 文件。上传的图片和视频保存在 `.runtime/uploads/`。当前实现适合本地开发与单机测试；上线前仍需部署 HTTPS、进程守护、定期备份，并根据正式服务器环境设置安全 Cookie 与反向代理。

本地预览：从项目根目录运行 `python3 scripts/dev-server.py`，浏览器打开 `http://127.0.0.1:4173/admin/`。
