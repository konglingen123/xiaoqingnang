# 小青囊 UI 设计系统

## 品牌识别

- 主品牌标识使用圆形“小青囊”字徽：上方为“小”，下方并列“青囊”。
- 标准色为竹青 `#397B63`、暖奶油白 `#FFF9ED`，柔桃 `#F49A86` 只作为单个记忆点使用。
- 小尺寸界面使用圆形字徽；空间充足时在右侧配完整品牌名与“日常养护技能库”说明。
- 养护伙伴属于 App 内陪伴角色，不替代主品牌标识，也不用于需要正式署名的场景。
- 不再使用单独“青”字方块、医疗十字、药丸、叶片或传统红色印章作为品牌 Logo。

## 一级导航与扩展

- 当前底部导航只显示首页、文集、我的。
- 首页承载养护方法与未来 AI 入口；文集只承担阅读；我的承载个人记录和设置。
- 练功打卡与轻养商城未来达到可用状态后再进入一级导航，不提前展示空栏目。
- 一级导航最多同时展示五项；超过五个业务域时使用首页场景入口或我的二级入口承接。

版本：1.0  
状态：实施基线  
设计方向：温馨糖果感健康 UI

## 1. 核心体验

小青囊不是医疗诊断产品，而是日常养护内容与跟做工具。界面应让用户感到被欢迎、被陪伴和容易开始，同时保持内容、安全边界与操作指令清楚可信。

体验关键词：

- 温馨：像进入一个愿意陪伴用户照顾身体的空间；
- 糖果感：颜色丰富、柔软明亮、圆润亲切，但不过度幼稚；
- 可信：来源、范围、操作参数与停止条件始终清楚；
- 低压力：不催促、不评判、不使用诊断式或恐吓式表达；
- 内容优先：装饰不遮挡操作，不用氛围代替准确指令。

一句话标准：

> 轻触有回应，切换有过渡，操作不催促，风险说清楚。

## 2. 色彩系统

所有糖果色应保持相近的柔和度、明度与暖色倾向，避免荧光色、冷灰色和脏色混用。

### 2.1 基础色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 暖奶油 | `#FFF8EA` | 页面背景、弹层背景 |
| 竹青 | `#1B5A47` | 主按钮、关键功能、可信感 |
| 深青文字 | `#183F34` | 标题和正文重点 |
| 柔和正文 | `#5E7068` | 说明文字 |
| 暖灰线 | `#EDE4D8` | 分隔与弱边界 |

### 2.2 糖果色

| 颜色 | 色值 | 情绪与主要用途 |
| --- | --- | --- |
| 奶油黄 | `#F4C85E` | 欢迎、开始、鼓励 |
| 蜜桃粉 | `#F3A58F` | 亲近、详情标题、完成反馈 |
| 薄荷绿 | `#BFE3CE` | 养护、选中、完成状态 |
| 丁香紫 | `#D8CCF1` | 分类、资料、辅助信息 |
| 浅陶土 | `#F7C7B8` | 注意、停止与风险边界 |

### 2.3 使用规则

- 每个页面使用一个主糖果色和一个辅助糖果色；公共功能统一使用竹青。
- 大面积背景使用暖奶油，彩色用于主视觉、分类卡和状态反馈。
- 同屏不平均分配所有糖果色，应有明显主次。
- 风险信息使用浅陶土色，并同时提供明确标题、图标或边框，不能只靠颜色。
- 正文区域保证足够对比度，禁止在浅糖果色上使用浅灰文字。

## 3. 形状与空间

- 大型主视觉圆角：`40–48rpx`；
- 内容卡圆角：`28–36rpx`；
- 小卡与控件圆角：`18–24rpx`；
- 筛选、主按钮使用胶囊圆角：`999rpx`；
- 图标底座优先使用圆形或柔和的不规则圆角；
- 页面左右安全边距：`24–30rpx`；
- 卡片间距：`16–20rpx`；
- 阴影轻柔，不使用厚重悬浮效果。

标准卡片阴影：

```css
box-shadow: 0 12rpx 30rpx rgba(67, 55, 45, 0.07);
```

## 4. 字体层级

- 页面主标题：`45–54rpx`，字重 `800–850`，可使用轻微负字距；
- 卡片标题：`28–31rpx`，字重 `700–760`；
- 正文：`22–24rpx`，行高 `1.65–1.85`；
- 辅助信息：`17–20rpx`；
- 功能指令必须直接、短、醒目；
- 现代无衬线字体为主，宋体只用于少量品牌性语句，不用于操作指令。

## 5. 组件规则

### 5.1 主视觉卡

使用一种主糖果色，可以加入一个简单圆形或叶片装饰。装饰不得覆盖标题、说明或操作入口。

### 5.2 内容卡

卡片默认暖白，也可以按顺序使用极浅的蜜桃、薄荷、丁香和奶黄底色。点击时缩小至 `0.985`，松开后恢复。

### 5.3 胶囊筛选

- 未选中：暖灰米色；
- 选中：竹青底、白字；
- 切换时间约 `200ms`；
- 内容区域使用淡入和轻微上移过渡。

### 5.4 主要按钮

竹青背景、白色文字、胶囊形状。按下时轻微缩小，不使用强烈弹跳。

### 5.5 空状态

使用奶油黄、薄荷绿或丁香紫的大圆角卡片。文案说明当前状态和下一步，不使用冰冷的“0 条结果”。

### 5.6 风险与停止

使用浅陶土背景、深陶土文字和清楚的“停止”表达。不得通过温馨设计弱化风险信息。

## 6. 动效与反馈

标准节奏：

- 点击反馈：`120–180ms`；
- 筛选与状态变化：`180–240ms`；
- 页面元素进入：`240–360ms`；
- 呼吸或陪伴动画：`3–5s` 循环。

推荐交互：

- 卡片按下轻微缩小；
- 胶囊筛选平滑换色；
- 搜索结果依次淡入；
- 人体部位出现柔光高亮；
- 来源弹层从底部柔和进入；
- 跟做进度平滑推进；
- 完成时使用柔和扩散或色块展开。

禁止：

- 高频闪烁；
- 强烈弹跳；
- 医疗扫描效果；
- 用红色痛点制造焦虑；
- 为装饰而持续运动；
- 以连续打卡、落后提醒制造压力。

系统开启“减少动态效果”时，必须停止非必要动画。

## 7. 页面色彩分配

- 首页：奶油黄主视觉，蜜桃与薄荷辅助；
- 青囊文集：暖奶油阅读底色，糖果色只用于封面、专栏卡与书签；
- 内容详情：蜜桃主视觉，奶油黄装饰，正文暖白；
- 人体浏览：薄荷绿主视觉，选中区域使用奶油黄柔光；
- 开始前准备：奶油黄或薄荷绿，风险区域使用浅陶土；
- 跟做页面：暖奶油和薄荷为主，减少装饰；
- 我的：蜜桃欢迎区，薄荷会员状态，丁香紫权益信息。

## 8. 文案语气

- 像陪伴，不像诊断；
- 温和，但不含糊；
- 不说“你有问题”，说“你想照顾哪里”；
- 不说“必须坚持”，说“按自己的节奏来”；
- 无结果时如实说明未收录，不临时生成建议；
- 出现风险时直接说“请停止操作”，不使用委婉表达。

## 9. 验收清单

- [ ] 页面有明确的主色和辅助色，没有平均堆叠所有颜色；
- [ ] 标题、正文与辅助文字层级清楚；
- [ ] 点击、切换与加载都有轻柔反馈；
- [ ] 动效没有干扰阅读和跟做；
- [ ] 安全信息没有因糖果色而被弱化；
- [ ] 空状态没有诊断、责备或冰冷表达；
- [ ] 开启减少动态效果后仍可正常使用；
- [ ] 页面与首页看起来属于同一个品牌家族。
