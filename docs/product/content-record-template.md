# 小青囊内容录入标准

## 1. 两种内容

后台只录入：

- **信息资料**：解释知识、原理、部位或经验背景。
- **养护方法**：用户可以依照图文查看或尝试的方法。

一条后台记录对应前台一张结果卡片和一个详情页。文章里有两个独立方法时，建立两条方法资料，不把多个方法塞进同一详情。

## 2. 共同字段

- 问题名称：结果卡片标题。
- 一句话说明：用户能在本页看到什么。
- 搜索关键词：用户可能输入的口语表达。
- 标准身体位置：只能从后台位置选择器选择，可多选。
- 访问方式：免费或会员。
- 图文正文：用户最终看到的文字、图片、GIF 和视频。
- 风险边界：不适用情况。
- 资料来源：原始资料标题、直接依据及可选作者、平台、链接、核验备注。

## 3. 方法资料附加字段

- 方法名称；
- 方法类型；
- 工具或材料，没有时填写“无”；
- 使用范围；
- 注意事项；
- 必须停止的情况；
- 可选案例集。

穴位或功法必须在图文正文中写清准确位置、查找方式、使用哪只手或工具、方向、力度、时间或次数、每日频率，并配准确图片或视频。当前先使用富文本，不拆结构化步骤；缺少真实参数时只能保存草稿。

## 4. 详情展示

方法资料的候选 Tab 顺序：

1. 方法；
2. 使用范围；
3. 注意事项；
4. 风险边界；
5. 案例集。

没有内容的 Tab 不出现；只有一个栏目时不显示 Tab 切换。信息资料按实际数据展示内容和风险边界。资料来源在当前页底部弹层展开。

## 5. 案例

案例不是效果证明。只收录真实、可追溯记录，并保留：

- 使用前的日常情况；
- 实际使用方法；
- 持续时间（可选）；
- 当事人主观记录；
- 个体差异与限制；
- 原文位置。

没有真实案例时保持为空。

## 6. 图片和视频

- 按最终阅读顺序插入正文；
- 每张图片必须说明身体方向、位置、标注和动作；
- 视频必须说明展示内容；
- 装饰图不能替代位置、方向和力度示范；
- 未确认商业使用权的原图不得直接上线。

## 7. 发布

后台实时检查缺项和公开用语。内容负责人确认来源、图文、方法参数和风险边界后发布。修改已发布内容会先退出公开状态，重新发布后才回到前台。

前台只读取发布接口。未通过检查的旧数据即使曾标记为已发布，也不会展示。

数据库字段和接口见 `database/schema.sql`、`server/index.js` 与 `typings/models.ts`。批量整理使用 `outputs/content-data-template/小青囊内容整理模板_v1.xlsx`；当前版本仍由管理员按表格内容录入后台。
