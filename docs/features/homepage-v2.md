# 首页 v2：人体图直跳 + AI 搜索（产品与交互规格）

> 状态：待评审。本文档经讨论收敛后定稿，代码实现前以本文档为准。
> 关联文档：`docs/features/ai-search.md`（技术方案）。

## 1. 背景与目标

当前首页是三步向导（选部位 → 拨罗盘 → 看方案列表），链路偏长；且方案库对"说不清哪里不舒服"的长尾需求没有承接。

v2 目标：

- **快**：点人体图小区域，1 步到达该部位的方案列表
- **全**：图上点不到的、说不清的，交给 AI 搜索兜底
- **合规不变**：去疾病化、免责常驻、AI 内容标识（新增）

## 2. 竞品调研结论（影响本设计的要点）

| 参照 | 结论 |
| --- | --- |
| WebMD 症状自查（11 主区域 + 41 子区域） | 点部位 ≠ 直达单一结果，而是"打开该部位的内容集合"；层级热区 + 最常见优先 |
| Ada Health（对话式一次一问，10~15 轮） | 追问太多是反面教材：追问必须 ≤3 轮，问题附"为什么问这个" |
| 腾讯医典 AI / 支付宝 AI 健康管家 | 多轮问答 + 就医建议分级 + 强制 AI 生成标识 + "AI 非人工服务"声明 |
| 微信平台 | **个人主体无法上「深度合成-AI问答」类目**；精确规则直返不算生成式 AI，可先行上架 |

## 4. 人体图交互

### 4.1 热区细分

组件已有 19 个正面热区 + 背面热区，硬件不变。变更的是 `areaId` 映射：从 5 个粗分区细分为小区域（提案如下，最终以内容覆盖为准）：

| 细分部位 id | 覆盖热区 | 需保证方案数 |
| --- | --- | --- |
| head 头 | head | ≥1 |
| neck 颈 | neck | ≥2（温敷 + 舒展） |
| shoulder 肩背 | shoulder-l/r、upperarm-l/r、upperback | ≥2 |
| waist 腰 | waist | ≥1 |
| belly 腹 | belly、groin | ≥2 |
| limbs 手足 | thigh/forearm/leg/palm/foot、buttocks | ≥1 |
| whole 全身 | —（兜底入口） | ≥2 |

**硬规则：点击任何热区都必须有响应。** 方案数不足的部位先不设独立热区，或走兜底。

### 4.2 点击行为

- 点击热区 → `uni.navigateTo` 进入**部位方案页**（新页面 `pages/area/area?id=<细分部位id>`）
- 高亮态 + 部位名标签气泡（组件已有，复用）

### 4.3 部位方案页（新页面）

结构（自上而下）：

1. 标题：部位名（如「颈」）+ 一句人话副题（如「这里紧绷，多半是它在抗议久坐」）
2. 方案列表：该部位方案 + 兜底方案（全身通用类），排序 =「最常用优先」（配置项 sortOrder），每张卡显示安全红绿灯角标
3. 卡片点击 → 现有 prepare 页（零改动）
4. 底部常驻 `disclaimer-bar mode="bar"`

### 4.4 空部位兜底

方案数为 0 的热区：显示「这个部位的方案正在路上 🌱」+ 推荐 1~2 个全身放松方案 + 引导「去问问 AI」。

## 5. AI 搜索交互

### 5.1 入口与路由分流

首页顶部搜索框（或独立入口按钮）→ 进入**对话页**（新页面 `pages/ai/ai`）。

**分流规则**（用户输入后）：

```
输入 → 规则引擎打分（别名词典命中）
  ├─ 精确命中（阈值以上）→ 直接返回方案列表【零 AI、零资质门槛】
  └─ 模糊/未命中 → AI 路径（阶段三接入）→ 方案列表 + 理由
       └─ AI 也无法匹配 → 兜底话术 + 通用放松方案 + 反馈入口
```

- 精确路径对用户完全无感（响应快，无标识）；AI 路径结果带 AI 标识
- 阶段二先实现精确路径 + 对话交互（本地模拟 AI），阶段三换真 LLM，**接口不变只换实现**

### 5.2 多轮对话骨架（AI 路径）

- 槽位模型：`部位`、`偏好`（如"不想泡脚""办公室能做"）；另有红旗词与禁忌词（孕妇等）。口语体感（"酸""僵"）由方案 aliases/scenarios 承接，不设独立槽位
- 自由输入 → AI 识别槽位 → 缺槽位则**追问，最多 3 轮**；每轮追问附 chips 快选（点击即答，不用打字）+ "为什么问这个"一句解释
- 槽位齐 → 输出方案列表（2~3 个）+ 一句推荐理由（≤50 字，AI 生成，须过禁用词过滤）
- 结果卡片点击 → 现有 prepare 页
- 未命中兜底：温和话术（不含医疗建议）+ 通用放松方案 + 「没解决？记录你的问题」反馈入口

### 5.3 红旗词与就医引导（合规红线 4，新增）

用户输入命中红旗词（高烧、剧烈疼痛、出血、晕倒、胸闷、呼吸困难等）→ **终止推荐**，输出固定就医话术（复用 `DISCLAIMER` 精神：高烧 >38.5℃ 或剧烈腹痛请及时就医），不接 AI、不追问。

### 5.4 标识与免责

- 对话页顶部常驻：「AI 建议不构成医疗意见」+「本内容由 AI 生成」标识（微信强制要求）
- AI 生成的任何文本输出前过禁用词过滤（见技术方案）

## 6. 会员与免费额度（建议方案，待确认）

- 规则直返路径：**永久免费**（无边际成本）
- AI 路径：免费额度 **每天 3 次**；超出 → 会员解锁（会员含更高额度 + 历史会话等）
- 第一版建议 AI 全免费 + 额度限制跑通，会员功能第二期上
- **风险**：微信小程序 iOS 端禁止虚拟支付——会员只能在安卓/H5 售卖，iOS 隐藏购买入口或引导公众号。虚拟支付类目另有资质要求。

## 7. 数据埋点

| 事件 | 字段 |
| --- | --- |
| 热区点击 | 细分部位 id |
| 部位页方案点击 | 部位 id、方案 id、排序位置 |
| AI 输入 | query 原文、路由结果（直返/AI）、槽位抽取结果、追问轮数 |
| AI 结果点击 | 方案 id、排名 |
| 未命中 | query 原文（**用于方案库扩充的依据**） |
