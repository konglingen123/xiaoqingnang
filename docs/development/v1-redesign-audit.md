# 小青囊当前改造盘点

日期：2026-09-04

## 保留

- uni-app、Vue 3、TypeScript 与 HBuilderX 的 H5 外壳。
- 首页自然语言搜索、人体图、固定风险拦截。
- 同域名独立后台、SQLite、素材上传、会员码和发布日志。
- 来源弹层、免责声明与会员服务端裁剪。

## 已改为当前主流程

- 内容只有“信息资料”和“养护方法”两种。
- 后台一条记录直接发布为前台一张卡片和一个详情页。
- 搜索、人体点击和内容库共享 `utils/content.ts`。
- 人体点击直接返回卡片，不进入部位中间页。
- 详情空 Tab 自动隐藏，来源在当前页查看。
- 方法正文使用富文本，可连续插入多张图、GIF 和视频。
- 后台身体部位只能选标准 `areaId`。
- 发布使用当前负责人自审，并在服务端再次检查缺项与公开用语。

## 已删除

- 旧搜索结果页与部位结果页。
- 问题 → 方法 → 方案 → 准备 → 播放器的多层页面链。
- 当前没有真实步骤数据却提前存在的准备页、播放器和完成反馈。
- 旧前端知识仓库、本地协议编译、收藏/最近执行假入口。
- AI 生成示例、固定三分钟、体质、蓄电、竹叶日历和疗效反馈。

## 以后再做

- 真实结构化步骤录入与可选跟做附件。
- 基于数据库白名单的 AI 多轮检索。
- 在线支付、真实会员套餐、收藏和历史记录。
- 正式上线前的内容责任人、安全与法律复核流程。
