# 小青囊功能架构

## 当前产品结构

小青囊当前只向用户开放三个一级入口：

1. 首页：查找经过审核的养护方法，并通过人体位置辅助查找。
2. 青囊文集：阅读文章、专栏和专题，保存阅读进度。
3. 我的：管理会员状态、收藏、阅读记录和个人设置。

文集文章与养护方法使用同一发布接口，但在前台严格分流。文章不进入首页方法搜索，方法不进入文集。

## 未来业务域

- AI 交互：作为跨模块能力接入，不绑定单一页面。可用于方法检索、文章问答和练功辅助，但只能引用已审核内容。
- 练功打卡：独立记录练习项目、计划、完成记录和连续天数，不把阅读记录伪装成练习。
- 轻养商城：独立维护商品、规格、订单与售后，不与文章或方法记录共用数据表。
- 青囊文集：可继续扩展专刊、作者页、音频、书签、批注、付费阅读与相关推荐。

## 模块边界

```text
shared     品牌 账户 会员 权限 媒体
methods    养护方法 搜索 身体位置 风险边界
anthology  文章 专栏 专题 作者 阅读进度 收藏
practice   练习计划 打卡 记录 提醒
commerce   商品 规格 购物车 订单 售后
ai         检索编排 引用 上下文 安全终止
```

新增功能优先建立独立模型与服务，再决定是否进入底部导航。未启用模块不显示空入口。
