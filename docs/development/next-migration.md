# Next.js 迁移说明

当前运行入口已统一为 Next.js App Router：

- `/`：首页自然语言搜索、身体位置入口和养护方法
- `/chat`：单轮对话式检索结果
- `/anthology`：青囊文集、专栏与文章搜索
- `/article/[id]`：单篇文章阅读
- `/account`：我的、测试登录和本地记录入口
- `/admin`：后台登录、文章管理、基础数据库入口
- `/api/*`：公开内容、后台认证、内容保存/发布、专栏、来源候选、Word 导入、媒体上传与图片代理

数据仍使用原 `.runtime/content.db`，没有复制或重建文章数据。公开列表接口只返回卡片所需字段；文章正文在详情接口按 ID 单独读取。

生产构建使用：

```bash
npm run build
npm start
```

`server/`、`admin/` 和旧 `pages/` 目录暂时保留为迁移回滚参考，不是当前运行入口。确认 Next 版本验收后再做物理清理，避免在验收前丢失回滚路径。
