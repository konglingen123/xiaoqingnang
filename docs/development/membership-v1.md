# 小青囊会员系统 V1

## 当前目标

会员系统只控制已审核内容的访问范围，不参与健康判断，也不改变安全提示。第一版先支持内测会员码，待主体、商户号和支付规则确认后再接在线支付。

## 已上线能力

- 内容后台可将一条资料设置为“免费内容”或“会员内容”。
- 后台“会员管理”可生成 30、90 或 365 天内测会员码。
- 用户端“我的”可输入会员码激活，并显示会员编号和到期日。
- 游客可以看到会员资料的名称、简介、使用范围和风险边界，但拿不到具体方法、案例与完整原始依据。
- 有效会员由服务器鉴权后获取完整内容；退出后内容重新锁定。
- 会员码只保存不可逆哈希，明文仅在生成时显示一次。
- 会员会话使用 HttpOnly、SameSite Cookie；正式环境写操作强制 HTTPS。

## 数据结构

- `members`：匿名会员身份与状态。
- `membership_entitlements`：权益来源、开始时间和到期时间。
- `member_sessions`：浏览器会员会话。
- `activation_codes`：一次性会员码、有效天数和使用状态。
- `admin_contents.payload_json.accessLevel`：内容访问级别，值为 `free` 或 `subscription`。

## 在线支付接入边界

当前没有伪造支付按钮、订单或价格。正式接入时新增订单与支付回调，不修改现有内容权限判断；支付成功只负责创建 `payment` 来源的权益记录。

支付接入前至少需要确认：经营主体、网站备案、HTTPS、商户平台、退款规则、自动续费提示与隐私政策。
