# 小青囊 H5 产品与开发基线

版本：2.0  
日期：2026-09-04  
状态：当前唯一实施需求

## 1. 产品目标

用户输入一句话或点击人体位置，就能从人工录入、可追溯、已发布的资料中找到相关内容。产品不生成方法，不作诊断或治疗承诺。

内容只分两套独立体系：

- **青囊文集**：用于阅读的文章、专栏与专题，保留作者和来源语境。
- **养护方法**：通过图文、GIF 或视频说明一个可以查看或尝试的方法。

一条后台记录对应一张结果卡片和一个详情页。当前不把问题、方法、方案、步骤拆成多层页面。

## 2. 用户流程

### 2.1 文字搜索

1. 用户在首页输入自然语言。
2. 固定风险词先行判断；命中时终止检索并显示固定提示。
3. 系统只检索数据库中已发布内容的标题、方法名、关键词、标准身体位置、说明和正文。
4. 返回零到多张卡片；无结果时如实告知。
5. 点击卡片直接进入该资料详情。

### 2.2 人体点击

1. 用户切换到人体模型。
2. 点击经过校准的标准部位。
3. 页面切回会话区域，直接显示关联该 `areaId` 的资料卡片。
4. 不再经过“部位页”“方案页”或其他中间页。

### 2.3 青囊文集

只展示已发布文章，并提供继续阅读、今日一篇、专栏与文章搜索。文集文章不进入首页养护方法搜索。

## 3. 结果卡片

进入详情前必须显示：

- 内容类型；
- 免费或会员；
- 预计阅读时间；
- 是否需要工具；
- 当前是图文查看还是已具备跟做能力。

不得在卡片中编造适用效果或推荐理由。

## 4. 单资料详情

### 青囊文集文章

按实际数据展示：内容、风险边界、资料来源。

### 养护方法

固定候选栏目为：

1. 方法；
2. 使用范围；
3. 注意事项；
4. 风险边界；
5. 案例集。

任何没有内容的栏目不显示。只有一个栏目时不显示 Tab 开关。资料来源通过当前页底部弹层查看，不打开新页面。

方法图文可包含多张图片、GIF 或视频，并严格按后台编辑顺序展示。一个页面只承载一个方法单元或一个经审核的组合方法。

## 5. 后台录入

后台固定在同域名 `/admin/`，不在前台提供入口。

### 5.1 共同字段

- 类型；
- 问题名称；
- 一句话说明；
- 搜索关键词；
- 一个或多个标准身体位置；
- 免费 / 会员；
- 图文正文；
- 不适用或风险边界；
- 原始资料标题与直接依据；
- 可选作者、平台、链接和核验备注。

### 5.2 方法资料附加字段

- 方法名称；
- 方法类型；
- 工具或材料（没有时明确填“无”）；
- 使用范围；
- 注意事项；
- 必须停止的情况；
- 可选案例集。

案例至少包含：使用前情况、实际方法、主观记录、个体差异或限制、原文位置。案例是记录，不是效果承诺。

### 5.3 编辑与发布

- 正文使用富文本，支持文字、标题、列表、引用、图片、GIF 和视频。
- 身体位置只能从标准位置表选择，不能自由输入。
- 系统实时显示完整度和缺项。
- 可在后台直接预览前台大致效果。
- 发布时由当前内容负责人确认来源、方法参数、风险和公开用语。
- 修改已发布内容后先退出公开状态，重新发布后才回到前台。
- 发布和撤回写入操作日志。

## 6. 数据与接口

后台数据库保存一条规范内容记录：

```text
id, type, title, summary, keywords, bodyAreaIds, accessLevel,
contentHtml, methodName, methodType, materials,
usageScope, notices, outsideScope, helpConditions,
cases, sourceTitle, sourceAuthor, sourcePlatform,
sourceUrl, sourceText, sourceNotes, status, version
```

发布接口只返回通过完整性与公开用语检查的记录。会员内容未解锁时，服务器移除正文、案例和原始资料，但保留风险边界。

前台统一转换为 `PublishedContentItem`，再由方法与文集选择器严格分流，不得复制正文数据。

## 7. 安全与合规

- 用户输入先做风险终止，再检索。
- 公开文案禁止诊断、治疗、治愈和保证效果表达。
- 不通过检查的旧数据即使状态曾为“已发布”，也不再进入公开接口。
- 风险边界永久免费。
- AI 不得补写正式方法、参数、禁忌、案例或来源。

## 8. 未来能力

### 跟着做

只有方法具备真实、审核完成的结构化步骤时才开放。步骤是方法的可选附件，不改变当前“一条资料一个详情页”的主模型。

### AI 对话

AI 只能输出结构化检索条件和白名单内容 ID。所有面向用户的方法、风险、来源和卡片文字仍来自数据库；模型无命中时必须返回空结果。

## 9. 当前验收标准

- 后台新录入并发布的文集文章只在青囊文集出现，不进入方法搜索与人体入口。
- 方法资料也走同一条链路。
- 一条资料只有一个详情页。
- 空 Tab 不出现。
- 来源不跳页。
- 会员锁定由服务器裁剪。
- 旧部位页、旧方案页、旧播放器不在正式路由或代码中。
- 接口测试、后台语法检查和公开内容扫描通过。
